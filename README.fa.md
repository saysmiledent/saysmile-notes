# SaySmile Notes — راهنمای راه‌اندازی

اپ یادداشت دست‌نویس برای دندانپزشکان: نوشتن با Apple Pencil، عکس و رادیوگرافی، قالب‌های آماده (نمودار دندان FDI و طرح درمان GAM)، اشتراک با همکاران، ثبت اینکه هر نوشته از چه کسی است، و خروجی PDF/PNG.

## ۱) بدون سرور امتحان کن (همین الان)
پوشه را روی یک وب‌سرور بگذار (یا `python3 -m http.server`) و `index.html` را باز کن. تا وقتی `config.js` خالی است، اپ در **حالت دمو** کار می‌کند: داده‌ها فقط روی همان دستگاه می‌مانند و از منوی (آواتار بالا) می‌توانی بین «Dr. A» و «Dr. B» جابه‌جا شوی تا بخش نویسندگان را ببینی.

## ۲) اتصال به Supabase (انجام شده برای پروژهٔ SaySmile؛ برای پروژهٔ دیگر این مراحل را تکرار کن)
1. در supabase.com یک پروژه بساز.
2. **SQL Editor** را باز کن، کل فایل `supabase/schema.sql` را Paste کن و Run بزن. (جدول‌ها، نقش‌ها، قوانین دسترسی و پوشهٔ عکس ساخته می‌شود.)
3. **Project Settings → API**: مقدار `Project URL` و کلید `anon / publishable` را در `config.js` بگذار. هرگز کلید `service_role` را آنجا نگذار.
4. **Authentication → Providers → Email**: روشن باشد. برای شروع سریع می‌توانی «Confirm email» را خاموش کنی.
5. **Authentication → URL Configuration**: آدرس سایت (مرحلهٔ بعد) را به‌عنوان Site URL بگذار.

## ۳) انتشار روی GitHub Pages
1. یک repo بساز و همهٔ فایل‌های این پوشه را آپلود کن.
2. **Settings → Pages → Deploy from a branch → main / root**.
3. روی آیپد در Safari آدرس را باز کن، **Share → Add to Home Screen**. اپ تمام‌صفحه و آفلاین‌پذیر می‌شود.

## ۴) کار با اپ
- **ابزارها:** ✋ انتخاب (حرکت‌دادن عکس، تایپ در فیلدها)، ✒ قلم (فشار Pencil اثر دارد)، ماژیک، پاک‌کن (کل خط را پاک می‌کند)، متن (هر زبانی که کیبورد دارد).
- **انگشت:** روی آیپد با Pencil می‌نویسی و با یک انگشت صفحه را می‌کشی، با دو انگشت زوم می‌کنی. اگر Pencil نداری گزینهٔ «Рисовать пальцем» را روشن کن.
- **عکس:** دکمهٔ تصویر؛ در قالب GAM عکس خودکار در اولین جای خالی می‌نشیند. در حالت ✋ روی هر کادر عکس بزنی همان کادر پر می‌شود.
- **اشتراک:** آیکن آدم‌ها ← ایمیل همکار + نقش (Просмотр / Редактор / Администратор). اگر همکار هنوز ثبت‌نام نکرده باشد، دعوت می‌ماند و با اولین ثبت‌نام با همان ایمیل فعال می‌شود. دسترسی به یک پوشه به همهٔ یادداشت‌های داخلش هم می‌رسد.
- **نویسندگان:** آیکن ساعت. روی نام یک دکتر بزن؛ نوشته‌های او با رنگ خودش دیده می‌شود و بقیه کم‌رنگ می‌شوند. «Активность» فهرست کارهای هر نفر است. دکمهٔ ساعت کنار هر مورد یادداشت را **همان لحظه** نشان می‌دهد.
- **خروجی:** آیکن دانلود ← PDF (همهٔ صفحه‌ها) یا PNG (صفحهٔ فعلی).

## ۵) قالب HTML خودت
فایل HTML را با «Загрузить свой HTML-шаблон» بارگذاری کن. برای اینکه خوب جا بگیرد، طراحی‌اش را روی کاغذ **794×1123 پیکسل** (A4) ببند؛ اگر بلندتر باشد کوچک می‌شود (حداقل ۵۰٪). نشانه‌ها:
- `data-field="patient"` روی `<input>` یا هر المان: فیلد متنی که با صفحه ذخیره می‌شود.
- `data-photo="1"` روی یک `<div>`: جای عکس (اندازه‌اش همان اندازهٔ div است).
هر جای دیگر را هم می‌شود آزادانه با قلم پر کرد. اسکریپت، iframe و لینک بیرونی از قالب حذف می‌شود.

## ۶) محدودیت‌های نسخهٔ ۱
- Supabase رایگان بعد از ۷ روز بی‌استفاده «Pause» می‌شود (از داشبورد دوباره روشنش کن). حجم رایگان: ۵۰۰ مگابایت دیتابیس و ۱ گیگ عکس.
- عکس‌ها برای آپلود به اینترنت نیاز دارند؛ خط‌ها و متن‌ها در صف آفلاین می‌مانند و بعداً فرستاده می‌شوند.
- ترتیب صفحه‌ها فقط به انتها اضافه می‌شود (جابه‌جایی صفحه هنوز نیست). PDF به‌صورت تصویر است، نه متن قابل انتخاب.
- ویرایش هم‌زمان یک صفحه خراب نمی‌شود (هر خط جدا ثبت می‌شود)، ولی فیلدهای تایپی «آخرین نوشته برنده» هستند.
- **اطلاعات بیمار واقعی:** قبل از استفاده، محل سرور و قانون 152-ФЗ را با کلینیک روشن کن. فعلاً با داده‌های آزمایشی کار کن. ضمناً در روسیه باید بررسی شود که `supabase.co` از شبکهٔ کلینیک باز می‌شود.

## ۷) ظاهر و برند
رنگ‌ها بالای `styles.css` در `:root` هستند (فعلاً رنگ موقت سبز-آبی). لوگوی SaySmile را بفرست تا جایگزین شود.
